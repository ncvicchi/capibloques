Estas ilustraciones PNG transparentes corresponden a los avatares de las categorías **Animales** y **Robots** del catálogo de preferencias.

Se generaron como conceptos 2D de cuerpo completo con siluetas compactas, extremidades gruesas y piezas visualmente conectadas para facilitar una futura reinterpretación como modelos 3D imprimibles. Antes de fabricar habrá que crear y validar los modelos tridimensionales, espesores, estabilidad, tolerancias y soportes; estas imágenes no son archivos de impresión.
